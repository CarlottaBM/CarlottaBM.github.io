Machine Learning

How can a model reveal the physics hidden in data?

I use machine learning to extract physical information from experimental measurements and to study decision-making in complex modeled systems.

I am especially interested in models whose behavior can be interpreted, tested, and connected back to the system that produced the data.

CR-39 nuclear track analysis

I am developing a machine-learning pipeline for CR-39 nuclear track detector images. The workflow combines ilastik-based preprocessing, feature extraction, and classification to distinguish etched track morphologies.

The broader goal is to infer latent physical information—such as particle energy, direction, and source parameters—from track geometry. This requires combining unsupervised and physics-informed methods with an understanding of how the detector and etching process shape the images.

Reinforcement learning

In a team project for Modeling with Machine Learning, I am exploring how a reinforcement-learning agent can learn decisions through interaction with a modeled environment. The project focuses on defining the environment and reward, training a policy, and evaluating what the learned behavior reveals about the underlying system.

The project code and ongoing work are available in our GitHub repository.
