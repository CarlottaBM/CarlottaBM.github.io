Numerical methods · physical models · machine learning

Machine Learning

I use machine learning to model physical systems, test scientific assumptions, and extract structure from experimental data.

I am especially interested in physically interpretable methods: models shaped by governing equations, boundary conditions, and measurement constraints rather than treated as black boxes.

Selected work

Physics-Informed Neural Networks

Coursework on PINNs for neutron transport, including trial functions, loss construction, and boundary-dependent model design.

Scientific image analysis

Image-analysis workflows for detector features and track geometry, using computational methods to turn imperfect measurements into physical evidence.

Simulation and numerical modeling

Python and QuTiP models of quantum algorithms, walks, transport, and coupled systems, used to compare theory with physical intuition.

What this demonstrates

  • Scientific Python, numerical modeling, and simulation-driven reasoning.
  • Comfort moving between mathematical models, experimental constraints, and code.
  • Interest in physically interpretable machine learning rather than black-box modeling.
