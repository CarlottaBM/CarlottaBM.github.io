# CarlottaBM.github.io

Personal website for Carlotta Barone MacDonald.

## Structure

- `index.html` — home page with the interactive research atom
- `pages/` — About, Contact, and five concise research direction pages
- `assets/` — CSS and JavaScript
- `media/` — images, CV, and other media files

## Notes

- To update the CV link, place the file at `media/CV.pdf` or edit the link in `pages/contact.html`.
- To update contact links, edit `pages/contact.html`.
- The research dropdown is defined in each page header. Keep it limited to pages with substantive content.


## Research pages

Research direction pages should stay concise and include short, self-contained blurbs about relevant work instead of linking to separate project pages.
